# 视觉定调与页面设计

用于新建演示或美化版式。已有模板、品牌与用户指定的参考优先；仅改文字或数据时不重新设计整套。

## 确定一个具体方向

先把主题、受众与用途转成一个可见的设计概念。在 `planning.md` 中用一小段说明：希望观众感受到什么，主要依靠什么视觉表达，以及怎样适配内容。需求明确时自主选择，不要求用户先挑风格。

“高级、极简、科技感”不足以指导制作。可以写成“像一本城市文化刊物：暖纸色底、墨色大标题、少量朱红重点，以建筑细节摄影和宽留白连接主题”。这只是说明具体程度，不能作为所有任务的默认主题。

少量方向示例，用于推导选择而非套用模板：

| 内容与目的 | 可采用的视觉语言 | 重点检查 |
|---|---|---|
| 产品发布，建立第一印象 | 产品特写、明显尺度差、精简文案、稳定背景 | 产品主体和关键特征是否突出 |
| 经营分析，解释证据 | 编辑式网格、清晰数字层级、克制的强调色、直接标注 | 结论与数据是否容易对应 |
| 文化或品牌故事，传递气质 | 有主题的摄影或插画、节奏性留白、讲究断行的标题 | 素材与内容是否具体相关 |
| 技术方案，说明系统关系 | 模块对齐、语义明确的连线、局部放大与连续步骤 | 关系、方向和边界是否清楚 |

明确少量可复用规则：标题/正文/标注的字号与字重，背景/正文/强调/数据系列的颜色角色，外边距和对齐基线，以及照片、图标、插画的统一处理。可直接记在策划稿，不需要额外设计系统文件。少量代表页实测这些规则后再批量复用。

## 根据内容构图

每页先选最需要被看见的内容，给它足够面积、位置或对比；辅助信息围绕它组织。焦点不等于每页都放巨大的数字，也可以是一组对比、一张照片或一条清晰关系链。

| 页面任务 | 构图起点 | 适用边界 |
|---|---|---|
| 封面或关键观点 | 大字与宽留白，或单一主视觉配短标题 | 标题保持可编辑；封面不塞全套目录和论点 |
| 比较与选择 | 共用基线的并列对象，差异处明确强调 | 比较尺度一致，避免装饰造成大小误导 |
| 解释数据 | 一张主图加直接结论，或数据大字配支撑图 | 结论不能超过数据所能证明的范围 |
| 讲述情境 | 全幅或局部出血图片，文字落在自然负空间 | 无合适素材时用排版表达，不硬塞图片 |
| 解释过程与系统 | 按真实关系布置节点、连接线与局部说明 | 流程表达顺序，组织关系不强画成流程 |
| 信息较多的阅读页 | 按理解顺序分组，采用紧凑而明确的编辑式层级 | 保留必需内容，避免用缩小字号解决一切 |

用共同的字体、色彩语义与对齐关系保持一致，用面积、位置、密度与素材组织变化。只有分组有意义时才使用卡片；连续比较页可保留相同布局。不规定暗封面、亮正文或固定次数的布局变化。关键页的冲击力来自主次和内容，正文页需要足够平静以便阅读。

## 排版与留白

- 先确认字体可用且覆盖中文、数字与符号。默认可用一个字体家族的不同字重建立层级；主题确实需要时再配另一种字体。
- 先排最长标题与最密集正文，验证所选字号、文本框和行距。字号按画布比例和实际观看距离判断，避免直接混用 CSS 像素与 PPT 磅值。
- 标题按语义断行，避免孤立一字、拆开数字与单位、标点悬在行首。中文正文不靠大幅增加字距制造“高级感”。
- 同级内容共用基线和间距；检查文本框内边距，不能只对齐外框。数字列按小数位或位数对齐；图表标注与表格也使用统一字体。
- 留白用于分组、突出与停顿。图片可出血，重要文字与数据留在安全区域。拥挤时先删除冗词、重组或在允许页数内拆分，保留必须呈现的事实、标签与限制，再考虑缩小字号。
- 检查文字与背景的明暗对比；彩色数据也用标签或形状帮助区分，不仅依赖颜色。强调集中在真正重要的内容上。

## 图片与图形

素材应承担说明情境、展示主体、提供证据或建立主题气质中的具体作用。用户素材优先；需要新素材时使用可用的搜索或图像生成工具，保留来源及必要的许可说明，不要求每页都有图片。

同套摄影控制色温、饱和度、明暗和主体尺度；插画与图标保持一致的笔触或几何语言。按页面实际比例选择清晰素材，并围绕主体裁剪；不要拉伸、裁掉标志、改变证据图片的含义。文字落在清晰的负空间；确需遮罩时只调到能阅读，避免遮住主体。少量图片做好构图，比堆满无关素材更有用。

图片可以承担主视觉或背景，标题、正文和数据仍单独制作。不要生成带整页文字和图表的图片再作为可编辑 PPTX。事实性图片不能被虚构画面冒充；需要可编辑的流程和关系图按语义用原生对象建立。

## 数据图表与表格

先明确要比较的是大小、变化、分布还是关系，再选图型。保留准确的数值、时间、单位、基线与比较范围；不使用夸张面积、透视或不合理截轴制造视觉冲击。

突出与当前结论相关的系列或时间段，其余证据保持可读。能直接标注时减少观众在图形和图例间来回寻找；去掉不承担阅读作用的网格、边框和重复标签。观察工具实际输出的图表标签和字体，不能以 API 已设置为验收依据。

表格区分表头、关键列与辅助信息，保留用户要求的行列，用行距、对齐和少量分隔建立层级；不默认每格上色或加粗边框。双格式使用同一份数据，PPTX 保留原生表格和图表。

## 双格式与动效

HTML 和 PPTX 共享核心构图、视觉焦点与证据，但允许按各自文本度量微调位置和换行。先验证主要视觉能在两种格式中成立；复杂装饰可作为局部图片，不能因此把需要编辑的对象变成图片。

只有顺序讲解、对比揭示或转场确实受益时才增加 HTML 动效。遵守减少动态效果偏好，打印和静态 PPTX 保留完整信息。先检查静态页面，不用动画掩盖层级与构图问题。
