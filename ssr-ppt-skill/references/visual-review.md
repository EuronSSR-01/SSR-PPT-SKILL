# 代表页校准与审美验收

新建或美化演示时使用，与内容、交互及原生可编辑性检查一起执行。审阅的是实际渲染后的成品；代码、对象清单和评分只提供辅助信息。

## 先用代表页验证视觉方向

较长演示先完成少量能暴露设计问题的页面，通常是封面、典型内容页和数据或复杂信息页。根据实际内容选择，不为凑齐样页而加封面或图表；短演示直接整体制作。已有演示局部修改时选择受影响页。

代表页使用真实内容和接近最终长度的文字，不能用短占位词或空白图框掩盖拥挤。检查最长标题、中文断行、素材裁剪和密集信息是否都适合选定方向。双格式任务要渲染两种格式的关键代表页，不能只看 HTML 后假定 PPTX 相同。

发现具体问题后修改构图或视觉规则，回写策划稿，再推广到全套。内部校准无需用户逐页确认；用户明确要求先审样稿时才止于该阶段。

## 先看整套，再看每一页

把全部最终页面排列成缩略总览，观察视觉规则是否连贯、重点页面是否突出、信息密度是否符合叙事。留意连续重复的布局和无意义的背景切换；重复若有助于同类信息比较则保留。总览用于检查节奏，不能判断小字是否可读。

逐张查看完整尺寸页面，并在实际演示尺寸下检查阅读效果。结合主题、受众和策划稿进行下列判断：

| 检查项 | 观察依据 | 常见修正 |
|---|---|---|
| 焦点 | 第一眼能找到主题或主要证据，重要性与视觉面积相符 | 重排主次、缩短标题、扩大关键图形，弱化竞争元素 |
| 层级与阅读顺序 | 标题、证据、解释和口径容易区分，视线无需反复跳转 | 调整字号、字重、分组和标注位置 |
| 构图与留白 | 对齐稳定，主体比例合适，留白帮助理解且无意外空洞 | 改变元素面积和位置，调整文本框内边距与间距 |
| 素材与主题 | 图片主体清楚、裁剪自然、风格连贯，能解释其与内容的关系 | 更换不相关素材或重新裁剪，必要时改用排版表达 |
| 中文与数据 | 换行自然，正文和标注可读，数字单位完整，图表比例准确 | 重排文字、调整图表与直接标注，核对实际字体 |
| 辨识度 | 关键页体现主题，视觉概念能在实际页面中看出来 | 改善主视觉、尺度关系或构图；避免只加阴影和渐变 |
| 使用场景 | 现场讲述能扫读，独立阅读能理解，模板要求得到保留 | 调整密度与解释位置，不能擅自删掉必需信息 |

“没有重叠”和“看起来整齐”只是部分证据。若策划中的重点在实际页面上不突出，需要解决具体构图问题；没有具体缺陷时无需为了显示迭代而强行改动。

## 修复与停止

在私有构建目录简短记录：页码、实际观察到的问题、采取的调整和复查结果。优先处理影响理解、阅读、事实或编辑的问题，再处理重点不突出、节奏单调等视觉问题。不要求固定评分、固定修改轮数或必须挑出缺陷。

修复后重新导出并查看受影响页；全局字体、配色或间距规则改变时检查全套。HTML 和最终 PPTX 分别渲染验收，两者视觉差异可以接受，但重要内容、焦点和编辑要求不能丢失。PPTX 以重新读取最终导出文件后的图像为准。

内容与事实正确、实际渲染可读、所选视觉方向成立、关键页面重点明确，且没有尚未解决的具体问题时完成。不能承诺所有受众都会觉得“惊艳”。能力或素材受限时说明影响，不用模型高分掩盖未做的检查。审美记录留在构建目录，不额外打包成用户未要求的报告。
